# auto-defense


**A neon-style tower defense game built with **Python and Pygame**, featuring automated turrets, enemy waves, projectile mechanics, and progressively increasing difficulty. Protect your defense line, destroy incoming enemies, and achieve the highest score before your lives run out!**


# Running

To run the game just:

**Clone the repo** 

then:

**execute these two commands(this for activate the virtual environment and run the game):**
 this for activate the virtual environment and run the game
- source venv/venv/bin/activate                                           
- python main.py
